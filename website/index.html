Play guitar. Get treated properly.

fuzzyband is a small family of free, open-source guitar plugins: a musical AI accompaniment that writes drum & bass MIDI as you play, and a fuzz pedal model that traces a real analog circuit. Everything is built straight from the public source — no accounts, no restrictions.

  1. Pick a plugin below and download it for your OS.
  2. Put it into your DAW's plugin folder.
  3. Insert it and play. (Route its MIDI out to a drum / bass instrument where relevant.)

Safe to download?

Yes. Everything on this page ships from the project's GitHub Releases — the same place the source lives. Every release is built fresh and the CI runs the tests on it.

macOS Gatekeeper note (unsigned builds)

macOS builds are unsigned (no paid Apple Developer certificate is involved), so Gatekeeper may warn the first time you open a plugin. To allow it:

  • Right-click → Open on the downloaded bundle instead of double-clicking, then choose Open, or
  • clear the quarantine flag once on the downloaded file, e.g. xattr -dr com.apple.quarantine /path/to/fuzzyband.vst3

Check packaging: the extensionless fuzzyband / Fairo file inside Contents/MacOS/ should be a self-contained binary (for fuzzyband it references @rpath/libonnxruntime…). See RELEASING.md.

Build from source

Every plugin also builds from source — clone the repo, configure with CMake, build. The exact command for each plugin is in its download section above. You'll need CMake 3.22+, a C++20 compiler, Git, and (for fuzzyband) ONNX Runtime.

About

  • fuzzyband — listens to your guitar and writes drum + bass MIDI in real time, locked to the host tempo.
  • Fairo — Pharaoh-style fuzz: switchable clipping, coupled Tone/High stack, solved per-sample.

Both are built with JUCE 8 and released for macOS (VST3 + AU + Standalone), Windows (VST3 + Standalone) and Linux (VST3 + Standalone).
