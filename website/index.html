Metal Accompaniment

Free AI metal drum + bass MIDI accompaniment for guitarists

Download Build from source Safety Versions

Play guitar. Hear a metal band play with you.

Metal Accompaniment listens to your guitar in real time and writes drum and bass MIDI so a kit and a bass VST in your DAW play along with you — locked to your project tempo. No tempo tapping, no manual pattern selection. Free and open source.

  1. Pick your platform below and download.
  2. Put the plugin into your DAW's plugin folder.
  3. Insert it on your guitar track, route its MIDI to a drum (ch 10) and a bass (ch 2).

Each package is self-contained — the AI model and runtime are bundled, so you don't need to install anything else.

Build it yourself

Prefer to build from source, or your OS isn't covered? Clone the repo and build with CMake. You'll need CMake 3.22+, a C++20 compiler, Git and ONNX Runtime. Full instructions live in the repository README. 

git clone https://github.com/niallgiblin/fuzzyband.git
cd fuzzyband

# macOS (ONNX runtime via Homebrew)
cmake -B build -DCMAKE_BUILD_TYPE=Release \
  -DMA_ENABLE_ONNX=ON \
  -DONNXRUNTIME_ROOT=/opt/homebrew/opt/onnxruntime
cmake --build build --parallel

# The plugin is written to build/MetalAccompaniment_artefacts/Release/{VST3,AU,Standalone}

Configure with -DMA_ENABLE_ONNX=OFF for a rule-based-only build that needs no ONNX Runtime (still fully functional, but without the trained model path).

Safe to download?

Yes. Everything ships from this repository's GitHub Releases — the same place the source lives. On every release the project is built fresh, and the CI runs the tests.

macOS Gatekeeper note (unsigned builds)

macOS builds are unsigned (there's no paid Apple Developer certificate), so Gatekeeper will warn the first time you open the plugin. To allow it:

  • Right-click → Open on the app/bundle instead of double-clicking, then choose Open in the dialog, or
  • clear the quarantine flag once on the downloaded file: xattr -dr com.apple.quarantine /path/to/Metal Accompaniment.vst3

Check the packaging: the extensionless Metal Accompaniment file inside Contents/MacOS/ should reference @rpath/libonnxruntime… (self-contained, not your homebrew path). See RELEASING.md.
